# 공식 기준가로 비교하는 화장품 추천

기본 피부 설문의 마지막에 화장품 가격이 중요한지 확인한다. 가격을 고려하는 경우에도 먼저 성분 자료, 피부 조건, 자극 및 기존 제품 중복 기준을 적용한다. 각 단계의 적합도가 가장 높은 후보와 2점 이내인 제품 가운데 공식 기준가가 확인된 후보를 비교한다. 새로 살 때 드는 제품 1개 가격을 사용한다. 가격을 고려하지 않는 경우에는 기존 적합도 순서를 유지한다. 가격 답변은 피부 유형이나 보습 단계 계산에 들어가지 않는다.

`src/data/officialPriceReferences.json`에는 제품 ID, 해당 용량, 한국 공식가, 출처와 확인 날짜를 기록한다. 브랜드 공식몰 또는 그 제품의 공식 자료로 등록된 국내 운영몰의 정가·소비자가만 사용한다. 쿠폰, 배송비, 제휴 링크 가격, 여러 개 묶음이나 다른 용량은 비교하지 않는다. 등록 후 45일이 지나거나 출처·용량이 맞지 않으면 비교와 표시에서 제외한다. 가격 자료가 없어도 적합한 후보가 제거되지는 않는다. 공식 가격은 실제 재고나 최종 결제 가격을 의미하지 않는다.
