## 정량 시험 요약의 범위

아래는 현재 국내 상세 이미지가 공개한 정밀도 그대로다.
다른 판매처의 더 세밀한 소수점 수치를 국내 기록에 혼합하지 않았다.

Test 02·03과 만족도 설문에 표기된 20명·기간을 Test 01의 값으로 추정하지 않았다.
Test 01의 해당 필드는 `null`로 저장한다. 논코메도제닉 표기도 결과 수치를 만들지 않는다.
Test 02·03의 연령 범위는 브랜드가 제시한 14~50세로 기록한다.
공식 문구의 성인남녀 표기를 모든 참가자가 성인이라는 확정으로 확대하지 않았다.
Test 02·03 사진은 개선율 상위 5개 사례라는 설명이 있어 `photoScope`에 남겼다.
선별 사진을 모든 참가자의 전형적인 결과로 설명하지 않는다.

`resultPercent`는 브랜드의 전후 변화 요약이며 방향을 `decrease`/`increase`로 구분한다.
전체 보고서·대조군·통계·측정 방법과 시험 당시 처방의 현재 처방 동일성은 미확인이다.
이 수치를 사용자의 기대 개선량이나 여드름·홍조 질환 치료 효과로 쓰지 않는다.
내부 B 등급은 공식 처방·부분 함량과 브랜드 인체시험 요약 확인 범위다.

## 100% 만족도의 계산 기준

GIF는 처음 프레임에 1%가 표시되는 애니메이션이므로 마지막 프레임까지 확인했다.
최종 표시는 흔적/스팟 느낌, 피지/트러블 느낌, 번들거림 느낌의 세 문항에 각각 100%다.
20명, 2022-09-03~10-04, (주)더마코스메틱 피부과학연구소라는 표기와
5점 척도에서 ‘보통 이상’을 긍정 답변으로 계산했다는 설명이 있다.
보통 응답을 포함하므로 엄격한 동의 응답률이나 치료 성공률로 해석하지 않는다.

주관적 응답은 `consumerEvidence`, `agreementPercent: 100`,
`responseThreshold: "at_least_neutral_on_5_point_scale"`로 별도 저장한다.
세 문항과 정량 피지·면포 변화율을 합치지 않으며 100%를 임상 개선율로 저장하지 않는다.
인접 사용자 리뷰의 경험담은 시험 결과를 확인하는 근거로 사용하지 않았다.

## careProfile과 추천 표시

이전 ID14는 명시적 다섯 축이 없어 성분·태그·제형으로 점수가 추론됐다.
새 값은 비교 효능 척도가 아닌 내부 휴리스틱이다.

| 축 | 이전 추론 → 검수 후 | 판단 |
| --- | --- | --- |
| 수분 지원 | 0 → 2 | 글라이콜·트레할로오스 등 보습 보조. 수분량 개선 비교 근거 미확인 |
| 가벼운 제형 | 9 → 9 | 가벼운 액상 제형과 잔여감 적은 사용감 설명 확인 |
| 진정 지원 | 0 → 2 | 알란토인 보조 범위. 민감 피부의 무자극 보장으로 확대하지 않음 |
| 막힘 관리 | 6 → 6 | 브랜드의 피지·블랙/화이트헤드 결과를 제한적으로 참고. 15%에 비례해 올리지 않음 |
| 장벽 지원 | 0 → 0 | 별도 장벽 회복 측정 근거 미확인 |

기존 `acne` 태그는 추천 엔진에서 염증성 고민에 가산돼 시험 범위보다 넓게 작용했다.
이를 제거하고 공식 용도에 맞춰 `sebum`, `pores`로 정리했다.
`pores`는 피지·면포 및 모공 외관 관리 보조 용도이며 영구적인 모공 축소를 뜻하지 않는다.
`closed_comedones`, `blackhead`, `soothing`, `barrier` 태그는 추가하지 않았다.
설명·표시 태그도 트러블 전반보다 피지·모공 외관 보조 범위로 수정했다.
공식 추천 대상에 복합성을 보완하고 `hydrationLevel: 9`,
`sensitivitySafe: false`, `beginnerFriendly: false`는 유지한다.
고함량 제품을 초보자·민감성의 기본 제품으로 넓히지 않는다.

피부가 건조하다는 이유로 3~4방울을 안내하던 문구는 소량부터 반응을 확인하도록 고쳤다.
브랜드는 적당량/몇 방울을 안내하며 피부 타입별 정량은 공개하지 않아 임의의 공식 용량을 만들지 않는다.
토너 다음·크림 전 사용, 작은 부위 확인·눈/상처 부위 회피·자극 시 중단,
낮의 SPF 30 이상 자외선 차단 안내를 반영했다.
국내 표의 기능성 화장품 해당 없음도 고려해 미백·치료 승인 제품으로 표시하지 않는다.

## 구매 확인과 저장 한계

국내 공식 페이지의 현재 20ml 표시 가격은 20,800원이다.
기존 쿠팡 링크 요청은 HTTP 403으로 상품·옵션·가격을 확인하지 못했다.
`purchaseLinkVerified: false`, `priceVerified: false`이며 기존 19,000원은 미검증 가격이다.
다른 판매처 가격으로 덮어쓰지 않았다. 구매·가격 검증 표시는 후속 UI 과제다.

기존 사용기록을 소급 변경하지 않는다. 새 추천 snapshot에는 다섯 축과 B·부분 공개 상태가 담긴다.
현재 snapshot은 시장·전체 출처·시험 상세를 보존하지 않으므로 제품 DB와 이 기록을 함께 확인해야 한다.
이번 변경은 ID14 데이터와 검수 기록에 한정한다.

## 추천 영향

동일한 수분감 10단계 × 고민 7종 × 상태 6종, 420개 합성 입력을 비교했다.
ID14 선택은 39 → 58개다. 31개 입력에서 세럼만 변경됐으며 빈 슬롯은 없다.

| 주요 고민 | 변경된 입력 수 |
| --- | --- |
| 염증성 트러블 | 6 |
| 좁쌀·막힘 | 3 |
| 블랙헤드·피지 | 11 |
| 번들거림 | 11 |

ID14에서 ID25로 4개, ID13으로 2개가 바뀌고,
ID13에서 ID14로 23개, ID29에서 ID14로 2개가 바뀌었다.
염증성 고민 6개에서는 ID14가 빠졌다. 피지·모공 용도에서는 선택이 늘었다.
클렌저·토너·크림의 제품 선택은 모두 동일하다.
변화는 태그와 다섯 축 보정에 의한 것으로 근거 등급이나 15% 함량을 직접 가산한 결과가 아니다.
합성 입력 점검은 실제 사용자 개선이나 타 제품 대비 효능을 검증하는 시험이 아니다.

검증: 기존 테스트 25개, production build, ESLint, diff 검사 통과.
제품 43개 중 ID14 외 42개 데이터는 동일하다.
420개 입력에서 민감성·강한 진정/염증 필요 상태에 ID14가 선택되지 않는 것도 확인했다.
