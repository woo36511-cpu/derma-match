`concerns: [barrier, hydration]`, `hydrationLevel: 5`, `texture: mid`, 기존 피부 타입과 계절은 유지했다.
판테놀 삭제와 성분 보완이 자동 추론 점수에 영향을 주지 않도록 다섯 축을 명시했다.
민감 피부 패치시험 표기를 참고해 기존 `sensitivitySafe: true`를 유지하되 작은 부위 확인·개인차를 안내한다.
이 플래그는 추천 필터용이며 모든 민감 피부에 안전하다는 선언이 아니다.
피지·모공·면포·여드름 태그를 새로 붙이지 않았다.

토너 다음·크림 전 적당량 사용이 공식 안내다. 피부 타입별 방울 수는 공개되지 않아 임의 1~4방울 문구를 제거했다.
아침 1회·저녁 2겹은 브랜드 사용 팁이며 필수 용량으로 만들지 않고 필요 부위 덧바르기로 표현했다.
건조함이 남으면 크림 사용, 처음 소량·작은 부위 확인, 상처 회피·이상 반응 중단을 안내한다.
공식 미백·주름개선 기능성 표기는 확인했지만 추천 범위를 치료·피지 관리로 넓히지 않는다.

## 추천 영향과 저장 제한

수분감 10단계 × 고민 7종 × 상태 6종의 420개 동일 합성 입력을 전후 비교했다.
ID23은 38 → 41개에서 선택됐다. 3개에서 ID2 → ID23으로 세럼만 변경됐다.
고민 없음 1개·염증성 고민 2개이며 기존 수분·장벽 보조 후보의 제형 적합도 보정에 따른 변화다.
염증 고민에서 선택된다는 사실은 치료 근거가 아니며 염증 관련 태그·막힘 점수는 추가하지 않았다.
클렌저·토너·크림 선택은 모두 같고 빈 슬롯은 없다. 실제 사용자 효능 검증이 아닌 추천 동작 점검이다.

국내 단품 표시 판매가는 28,000원이지만 기존 쿠팡 링크의 상품·옵션·판매가를 대조하지 못했다.
`purchaseLinkVerified: false`, `priceVerified: false`다. 기존 가격을 공식 판매처 검증값으로 표시하지 않는다.
현재 사용기록 snapshot은 다섯 축·근거 등급·함량 공개 상태만 일부 보존하고 시장·전체 출처·시험 상세는 보존하지 않는다.
과거 기록은 소급 변경하지 않는다. snapshot 확장은 후속 저장 구조 작업에서 처리해야 한다.

검증: 기존 테스트 25개, production build, ESLint, diff 검사 통과. ID23 외 42개 제품 데이터는 동일하다.
