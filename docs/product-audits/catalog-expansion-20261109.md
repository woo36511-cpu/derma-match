- ID58 일리윤 집중 크림: 상품 페이지에 여러 구형 성분표가 있으므로 현재 SKU 222083에 연결된 CPP-40 표기 처방만 사용했다.
- ID63 약콩 판테놀 크림: 판테놀 2,550ppm = 0.255%. 5%로 표기하지 않는다.
- ID69 어니언 앰플 플러스: 정제수로 시작하는 현행 처방과 양파추출물 1,000ppm. 구형 양파85%·판테놀5% 수치를 가져오지 않는다.
- ID73 순정 2x 크림: 현행 SKU에는 기존 인터넷 성분표의 시어버터·글리세린이 없어 대표 성분에서 제외했다.
- 공개된 히알루론산 복합체 총량과 단일 히알루론산 농도를 구분한다. 함량 순서로 미공개 백분율을 추정하지 않는다.

## 구매 링크와 파트너스 링크

신규 23개 중 13개는 쿠팡 일반 상품 링크, 10개는 공식몰 판매 페이지를 연결한다. 일반 쿠팡 링크는 수익 링크가 아니다.

`src/data/productAffiliateLinks.json`에 제품 ID별 `originalUrl`, `affiliateUrl`을 별도 보관한다. 쿠팡 일반 링크와 원본 URL이 정확히 일치하고 `link.coupang.com` 또는 `coupa.ng`의 HTTPS 링크일 때만 구매 버튼에 우선 적용한다. 공식몰은 쿠팡 링크로 바뀌지 않는다. 링크가 없거나 잘못된 링크여도 추천 점수에는 영향을 주지 않는다.

파트너스 API를 통한 실제 자동 발급은 아직 연결하지 않았다. 사용자 계정의 API 사용 가능 여부와 비공개 키 설정이 필요하다. 현재 구현 범위는 제휴 링크 저장·검증·화면 자동 적용이며, 인증 키나 개인 AF ID를 임의로 만들지 않는다.
