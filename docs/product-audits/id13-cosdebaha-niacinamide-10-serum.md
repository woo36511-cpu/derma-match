## 함량 공개와 근거 등급

| 성분 | 저장한 함량 | 해석 |
| --- | --- | --- |
| 나이아신아마이드 | 10% | 브랜드가 공개한 해당 원료의 배합률 |
| 징크피씨에이 | 1% | 징크PCA 원료의 배합률. 순수 아연 1%를 뜻하지 않음 |
| 소듐하이알루로네이트 | null | 존재만 확인, 함량 미공개 |
| 판테놀 | null | 존재만 확인, 함량 미공개 |

공개된 두 함량은 `concentrationVerified: true`,
`concentrationBasis: "ingredient_fraction"`으로 기록한다.
이는 브랜드의 원료 배합률 표기를 확인했다는 뜻이며 독립적인 분석값이 아니다.
전체 성분의 농도가 공개된 것은 아니므로 `partially_disclosed`다.
60ml 이미지의 별도 함량 표기를 30ml의 히알루론산 함량으로 가져오지 않는다.

현재 국내 상세의 효능 설명과 7/10 등의 그래프는 원료 특성으로 범위를 제한한다.
완제품 인체시험의 표본 수·방법·기간·측정 결과는 확인한 공식 자료에서 찾지 못했다.
그래프나 10%·1%를 완제품의 개선율·치료효과로 환산하지 않는다.
`clinicalEvidence.humanStudyAvailable: false`는 이번 확인 자료에 인체시험 근거가 없다는 기록이며
세계 어디에도 시험이 없다는 확정이 아니다. 임의의 표본·시험 결과를 만들지 않고 `studies: []`로 둔다.
내부 C 등급은 공식 처방·일부 함량은 확인했지만 완제품 임상 근거를 확인하지 못한 범위다.

## careProfile 보정과 표시

이전 ID13은 명시적 `careProfile`이 없어 대표 성분 1종·태그·제형으로 점수가 추론됐다.
새 값은 기존 엔진과 같은 다섯 축을 수동 지정한 내부 휴리스틱이며 임상 효능 척도가 아니다.

| 축 | 이전 추론 → 검수 후 | 판단 |
| --- | --- | --- |
| 수분 지원 | 0 → 3 | 공식 처방의 글리세린·히알루론산·판테놀을 반영. 고보습 비교 근거는 없음 |
| 가벼운 제형 | 9 → 8 | 가벼운 에센스 설명과 과량 사용 시 끈적임 안내를 함께 고려 |
| 진정 지원 | 0 → 2 | 판테놀·알란토인 보조 범위. 고함량 제품의 개인별 자극 가능성 유지 |
| 막힘 관리 | 9 → 3 | 모공+피지 태그의 자동 합산을 줄이고 유분 관리 보조만 반영 |
| 장벽 지원 | 0 → 1 | 판테놀 등 보습 보조 수준. 장벽 회복 수치 미확인 |

현재 국내 자료의 피부 톤·유분 관리 용도에 맞춰 `concerns`를 `sebum`으로 제한했다.
예전 글로벌의 다른 처방에 붙은 모공 문구를 현재 국내 제품의 직접적인 막힘 제거 근거로 쓰지 않았다.
모공 태그는 제거하고 표시 태그를 피부 톤으로 바꿨다.
여드름·좁쌀·블랙헤드·장벽·진정 태그를 새로 추가하지 않았다.
기존 `hydrationLevel: 8`, `sensitivitySafe: false`, `beginnerFriendly: false`는 유지한다.
추천 엔진을 변경하거나 성분 농도에 비례해 점수를 올리지 않았다.

피부가 건조하다는 이유로 3~4방울을 안내하던 사용량은 모든 피부에서 1~2방울부터 시작하도록 수정했다.
보습 부족은 크림으로 보완하고, 사용 전 작은 부위 확인·눈 주변 회피·자극 시 중단을 안내한다.
작은 부위 확인만으로 이후 알레르기나 자극이 없음을 보장하지 않는다.
토너 다음·크림 전 사용과 낮의 자외선 차단 안내를 반영했다.
국내 상세의 ‘기능성 화장품 심사 해당사항 없음’ 표기를 고려해 미백 기능성 승인 제품으로 표시하지 않는다.

## 구매 확인과 한계

국내 공식 페이지의 30ml 표시 가격은 15,800원이고 품절 표시가 있다.
공식 사이트의 여러 상품에 같은 품절 표시가 있어 이를 단종이나 모든 판매처의 구매 불가로 확정하지 않았다.
현재 글로벌 사이트는 개편 안내와 가격 0 표기가 있어 실제 무료 구매 가격으로 해석하지 않는다.
기존 쿠팡 링크는 HTTP 403으로 옵션·제품·가격을 확인하지 못했다.
`purchaseLinkVerified: false`, `priceVerified: false`이며 기존 21,000원은 검증된 현재 가격이 아니다.
다른 채널 가격으로 덮어쓰지 않았다. UI의 구매·가격 검증 표시는 후속 과제다.

## 추천 영향과 검증

동일한 수분감 10단계 × 고민 7종 × 상태 6종, 420개 합성 입력으로 전후 비교했다.
ID13 선택은 53 → 28개다. 총 25개 입력에서 세럼만 변경됐다.

| 입력의 주요 고민 | 세럼이 바뀐 입력 수 |
| --- | --- |
| 좁쌀·막힘 | 16 |
| 블랙헤드·피지 | 5 |
| 번들거림 | 4 |

대체 선택은 ID14 20개, ID6 2개, ID29 2개, ID2 1개다.
클렌저·토너·크림 선택은 모두 동일하고 빈 제품 슬롯은 없다.
이 결과는 합성 입력 회귀 점검이며 사용자의 실제 개선·효능 비교를 검증한 것은 아니다.
ID14 등 남은 제품 검수와 태그 기반 점수 구조 재설계는 계속 필요하다.
근거 등급·함량 메타데이터 자체는 추천 점수에 직접 가산되지 않는다.
변경 영향은 ID13의 태그와 다섯 축 수정에서 나온다.

기존 사용기록을 소급 변경하지 않고 새 추천 snapshot에 검수된 다섯 축과 C·부분 공개 상태를 담는다.
현재 snapshot은 시장·전체 출처·시험 상세를 보존하지 않아 제품 DB와 이 검수 기록을 함께 확인해야 한다.
이번 변경은 ID13 데이터와 검수 기록에 한정한다.

검증: 기존 테스트 25개, production build, ESLint, diff 검사 통과.
제품 43개 중 ID13 외 42개 데이터는 동일하다.
420개 입력에서 민감성·강한 진정/염증 필요 상태에는 ID13이 선택되지 않는 것도 확인했다.
