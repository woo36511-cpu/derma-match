고순도·원산지 원료 설명이나 다른 판매처의 “100%” 표현으로 수치를 채우지 않았다.

## careProfile과 추천 표시

아래 값은 추천용 내부 평가이며 임상 측정값이 아니다.
전 제품에 통일된 검수 척도가 완성되지 않았으므로 상대 순위 역시 효능 비교로 해석할 수 없다.

| 항목 | 변경 전 → 후 | 판단 근거 |
| --- | --- | --- |
| 수분 지원 | 5 → 5 | 보습 성분과 수분 용도 확인. 크림 수준의 보습 지속 근거는 없음 |
| 가벼운 제형 | 10 → 9 | 워터·비점착 제형 설명 확인. 최대 적합도 10을 뒷받침하는 사용자 비교는 없음 |
| 진정 지원 | 9 → 7 | 진정 용도와 병풀 존재 확인. 함량 및 완제품 붉어짐 개선 효과의 크기는 미공개 |
| 막힘 관리 | 0 → 0 | 논코메도제닉 시험을 막힘 치료 능력으로 전환하지 않음 |
| 장벽 지원 | 2 → 2 | 보습 보조 범위. 장벽 회복 지표나 지질 보충 근거를 추정하지 않음 |

공식 용도에 따라 `hydration` 태그를 추가했다. `hydrationLevel: 6`은
기존 수분감 추천 단계로 유지했다.
`sensitivitySafe: true`는 기존 민감 피부 후보 필터용으로 유지했다.
향료·에센셜오일이 없는 확인 전성분과 브랜드 피부자극 시험 표기를 참고했으며,
알레르기·개인별 자극 없음의 보장은 아니다. 설명과 주의문에서 개인 반응 확인을 안내한다.
약산성·논코메도제닉 표기를 피지·여드름 치료 태그로 추가하지 않았다.

기존 쿠팡 제휴 링크는 접근 시 HTTP 403으로 상품·옵션을 검증하지 못했다.
`purchaseLinkVerified: false`로 유지했다. 기존 18,900원은 구매처의 현재 가격으로
검증되지 않았으므로 `priceVerified: false`를 남겼다.
공식몰 26,000원을 다른 구매처의 가격으로 덮어쓰지 않았다.
현재 UI는 가격 검증 플래그를 표시하지 않으므로 가격·구매처 정리는 별도 남은 작업이다.

## 추천 영향과 검증

수분감 1~10단계 × 고민 7종 × 상태 6종의 420개 합성 조건에서
동일 입력으로 변경 전후 `buildDynamicRoutine` 결과를 비교했다.
상태는 기본·민감·수분 필요·가벼운 제형 필요·진정 필요·염증 신호다.
실사용 효과나 실제 유저 분포를 나타내는 표본은 아니다.

재현용 입력은 아래와 같다. careNeeds의 생략 항목은 0이다.

| 상태 | isSensitive | hydrationNeed / lightTextureNeed / soothingNeed / congestionCareNeed / inflammationCareNeed |
| --- | --- | --- |
| 기본 | false | 0 / 0 / 0 / 0 / 0 |
| 민감 | true | 0 / 0 / 0 / 0 / 0 |
| 수분 필요 | false | 9 / 3 / 3 / 0 / 0 |
| 가벼운 제형 필요 | false | 3 / 9 / 0 / 7 / 0 |
| 진정 필요 | true | 5 / 5 / 9 / 0 / 6 |
| 염증 신호 | true | 5 / 5 / 6 / 0 / 9 |

각 상태에 mainConcern none, inflammatory_acne, closed_comedones,
blackhead_sebum, dehydration, sensitivity_redness, oiliness를 각각 적용했다.

| 항목 | 결과 |
| --- | --- |
| ID25 세럼 선택 | 93 → 57개 조건 |
| 전체 루틴 변경 | 74개 조건, 모두 세럼 교체 |
| 세럼 이동 | ID25→ID29 52개, ID25→ID2 3개, ID29→ID25 19개 |
| 클렌저·토너·크림 | 420개 조건 모두 동일 |
| 빈 제품 슬롯 | 없음 |

ID29로 이동한 결과는 해당 제품의 공식 근거가 더 강하다는 뜻이 아니다.
ID29(아누아 어성초 80 수분 진정 앰플)와 ID2의 후속 검수가 필요하다.
일부 조건에서는 수분 태그 추가로 ID25가 새롭게 선택된다.

기존 설문·추천·피드백·저장 흐름 테스트 25개, production build, ESLint와
diff 검사가 통과했다. 제품 개수 43개 및 ID25 이외 제품의 데이터 동일성도 확인했다.
추천 엔진·설문·저장 스키마·기존 사용기록은 변경하지 않는다.
