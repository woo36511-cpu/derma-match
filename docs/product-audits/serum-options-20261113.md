- PDRN·판테놀·펩타이드는 해당 추가 관리 질문에서 먼저 비교하고 싶은 제형으로 선택할 수 있다. 현재 상태, 보습 단계, 사용 중인 성분군을 먼저 확인한다. 이미 편하게 사용하는 세럼은 기본 세럼 구매로 이어지지 않는다.
- 순수 비타민 C 13%는 경험이 있고 해당 후보를 원한다고 답한 경우에만 비교한다. 민감 응답, 현재 따가움·당김, 높은 장벽 관리 필요도, 선택한 기존 비타민 C·레티노이드·각질 관리제·펩타이드 또는 중복 성분은 해당 후보에서 제외한다.
- PDRN 제품은 `재생 세럼`으로 검색할 수 있으나 피부 재생, 시술 대체, 흉터 치료 효과를 추천하지 않는다. [특정 제형의 도포 연구](https://pubmed.ncbi.nlm.nih.gov/42430369/)를 개별 판매 제품의 효능으로 옮기지 않는다.
- 정확한 동일 용량의 쿠팡 상품 색인을 확인한 제품은 일반 구매 링크를, 리뉴얼 토리든과 아누아는 정확한 공식 판매본으로 연결한다. 실시간 재고·판매처 로트·효과 검증은 별개다. 제휴 링크는 신규 발급하지 않았다.

대표 기본 설문 기준으로 지성·반복 자극의 세안제·세럼·크림과 건성의 토너 후보가 각각 1개에서 2개로 늘었다. 제품 적합도 값은 제형과 보습을 비교하는 내부 기준이며 실제 피부 개선률이 아니다.
