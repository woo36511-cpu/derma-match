# 국내 공식몰 검색 목록 확장

`routineLookupExpansion.json`은 브랜드 국내 공식몰에서 확인한 검색용 목록이다. 등록 항목은 브랜드, 판매 페이지에 표시된 제품명, 형식상 확인된 종류, 용량, 공식 상세 URL, 목록에 제품 이미지가 있을 때 그 이미지 주소로 제한한다. 제품명·용량 등은 브랜드 목록 기준이며 현재 판매·재고·전성분을 보증하지 않는다. 별도의 추천 후보 DB나 적합도 점수에는 들어가지 않는다. 동일 공식 상세 페이지에서 이전에 등록한 용량이 일치하면 기존 항목을 재사용한다. 다른 용량과 리뉴얼 표기는 남긴다.

1. 작업 폴더에서 `node scripts/sync-official-routine-catalog.mjs /tmp/dearsince-official-catalog --fetch`를 실행한다. 정해진 브랜드의 공식 페이지에만 요청하며, 원본 HTML은 작업용 임시 폴더에 둔다. 이미 받은 페이지를 재검토할 때는 `--fetch`를 빼고 실행한다.
2. 브랜드별 성공 페이지 수, 제품 수와 검색 제외 결과를 점검한다. 수집 실패는 품목 삭제로 간주하지 않는다. 공식 출처가 불분명한 제품·리뉴얼·용량 옵션은 임의로 합치지 않고, 기획 세트·증정·판매 홍보용 중복 페이지는 제외한다. 여러 판매 채널의 유사 이름을 자동으로 동일 처방이라 가정하지 않는다.
3. `node --test scripts/official-routine-catalog.test.mjs`와 앱 테스트를 실행한다. 배포 전 브랜드명으로 검색하고, 현재 사용감 기록에 담을 수 있는지 확인한다. 자동 전성분 확인을 지원하는 브랜드는 공식 자료가 일치하는 경우에만 후속 질문과 성분 중복 확인에 사용한다. 검색에만 등록된 나머지 제품은 검수 전 사용감을 받거나 검수 요청으로 이어진다.

식약처 공개 데이터는 원료성분 정보와 일부 기능성 제품의 심사·보고 정보를 제공한다. 이 목록을 모든 시판 제품의 전성분으로 대체하지 않는다. 제품 단위 수집은 확인 가능한 국내 공식 자료가 늘어날 때 계속 확장할 수 있다.
