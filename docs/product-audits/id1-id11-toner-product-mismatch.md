# ID1 독도 토너 · ID11 에빠끌라 듀오 목록 신뢰도 검수

검수일: 2026-10-11.

## ID1 라운드랩 1025 독도 토너 200ml

- [브랜드 공식 국내 상품 페이지](https://roundlab.co.kr/product/1025-%EB%8F%85%EB%8F%84-%ED%86%A0%EB%84%88-200ml/22/)에서 상품명과 용량을 확인했다. 그러나 접근 가능한 공식 텍스트에는 전성분을 확인할 수 없었다.
- [신세계몰 상품고시 전성분](https://shinsegaemall.ssg.com/item/itemView.ssg?itemId=1000031697295&salestrNo=6005&siteNo=6004)에서 16성분을 확인했고, 이 순서로 `fullIngredients`에 기록했다.
- 기존 대표 성분 `히알루론산`은 해당 16성분에서 찾을 수 없어 제거했다. 원료 함량 미공개로 남긴다.
- 브랜드가 직접 현재 국내 전성분을 확인해 준 것은 아니므로 `fullIngredientsMarket: "domestic_retailer"`, `domesticFormulaVerified: false`로 저장한다. 실물 라벨·리뉴얼 동일성은 후속 확인 필요.
- 대표 성분과 기본 진정 점수를 보수적으로 수정했다. 수치들은 내부 추천 비교용 휴리스틱이며 완제품의 효능·무자극 보장을 뜻하지 않는다.
- 공식 인체시험을 확인하지 않았으므로 기존 무자극 확정처럼 읽힐 수 있는 '저자극' 평가는 '가벼운 토너'로 조정했다.
- 기존 쿠팡 판매 링크 및 가격 12,900원은 재검증하지 않았다. `purchaseLinkVerified: false`, `priceVerified: false`다.

## ID11 라로슈포제 에빠끌라 듀오

- 기존 DB는 `category: "cream"`, 40ml, '에빠끌라 듀오' 이름으로 등록되어 있다.
- [현재 라로슈포제 국내 공식몰](https://www.larocheposay.co.kr/product/view/4416.do)은 **에빠끌라 듀오+M 에센스** 40ml로 표시한다. 현재 공식 INCI에는 살리실릭애씨드·카프릴로일살리실릭애씨드가 포함돼 있다.
- 예전 DB 상품과 현행 듀오+M 처방의 동일성, 쿠팡 검색 링크가 매칭하는 옵션, 크림 대체 제품으로 추천해도 되는지 확인하지 못했다.
- 다른 현행 제품의 전성분을 기존 ID11에 덮어씌우지 않는다. 현재 `isAvailable: false` 처리하여 **기본 루틴의 크림으로 추천하지 않는다.** 기존 ID와 이름은 사용기록 호환을 위해 유지한다.
- 현행 듀오+M을 신규 등록할 경우 별도 ID 및 유형·사용단계 검수하고, 구매 링크를 확인해야 한다.

## 추천·테스트
- 변경 제품은 ID1과 ID11뿐이다.
- 43개 제품 ID는 유지하고 과거 사용기록 구조는 건드리지 않는다.
- 기존 420개 합성 루틴 검증·전체 npm 테스트·ESLint·빌드는 자동 GitHub Actions로 검증한다.
- 기존의 미검증 제품을 임의로 안전하다고 가정하거나 전성분을 추측해 입력하지 않는다.
