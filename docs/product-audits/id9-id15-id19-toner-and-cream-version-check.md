# ID9·ID15·ID19 리뉴얼·성분 출처 검수

검수일: 2026-10-11.

## ID15 라운드랩 자작나무 수분 토너 300ml
- [라운드랩 제품 목록](https://roundlab.co.kr/product/list.html?cate_no=50)에서 현행 자작나무 수분 토너 300ml 상품명·규격을 확인했다.
- [SSG 300ml 상품고시](https://www.ssg.com/item/itemView.ssg?itemId=1000031717269)에서 전성분 21종을 순서대로 기록했다.
- 자작나무수액 **10,000ppm**은 유통사가 게시한 특정 성분 배합량이며 현재 제조사 라벨을 독립적으로 확인한 수치가 아니다. 피부 수분 상승률, 수부지 개선 가능성 및 전체 보습 성분 함량으로 환산하지 않는다.
- 추천용 대표성분은 글리세린/히알루론산/판테놀/자작나무수액으로 정리. careProfile은 수분7·가벼움9·진정4·막힘0·장벽2(내부 정성 평가).
- `fullIngredientsVerified: true`는 **유통사 공개 목록과 저장값 일치** 의미이며 `fullIngredientsMarket: domestic_retailer`, `domesticFormulaVerified: false`로 제조사 공식 현재 처방의 최종 라벨 확인과 분리한다.
- 쿠팡 가격·옵션·링크 유효성은 별도 확인 필요.

## ID9 아누아 어성초 77 토너
- 현재 [아누아 국내 공식몰](https://anua.kr/product/detail.html?cate_no=84&product_no=496)은 **[NEW/리뉴얼] 어성초 77 히알루론산 수분 진정 토너 250ml** 제품을 표시하고 전체 성분 목록도 게시한다.
- 기존 DB는 `어성초 77 토너`이며 현재 리뉴얼 제품과 성분·판매 쿠팡 옵션 동일성을 검증하지 않았다.
- 현재 신제품의 전성분을 구형 ID에 무조건 대입하지 않는다. 대신 `isAvailable: false`, `fullIngredientsVerified: false`, D등급으로 상태를 보존한다.
- 국내 공식몰에서는 리뉴얼 상품이 존재함을 확인했지만 **기존 판매 전 품목 단종을 확정하지 않는다.** 이후 쿠팡 연결 상품 확인과 신제품 신규 등록을 별도 작업으로 수행할 것.

## ID19 라운드랩 자작나무 수분 크림 80ml
- [라운드랩 공식 제품 페이지](https://m.roundlab.co.kr/product/%EC%9E%90%EC%9E%91%EB%82%98%EB%AC%B4-%EC%88%98%EB%B6%84-%ED%81%AC%EB%A6%BC-80ml/94/category/105/display/1/)에서 정체성과 규격을 확인한다.
- [기존 SSG 기획 세트 상품고시](https://www.ssg.com/item/itemView.ssg?itemId=1000031715471)의 크림은 비교 가능한 **구버전 37종 전성분**을 게시한다. [2026년 9월 기획 제품 데이터](https://kbeauty-digest.com/olive/A000000263179)는 **59종**을 표시하지만 성분 표기는 원래 표기 순서를 복원하지 못한 2차 수집 자료다.
- 이름과 용량이 같다고 37종과 59종 처방이 같다고 가정하거나 두 목록을 섞지 않는다. 현재 쿠팡 옵션이 어느 처방인지 미확인.
- 정식 현행 제조사 라벨 및 제품 옵션을 확인할 때까지 `fullIngredientsVerified: false`와 `isAvailable: false`로 잠정 추천 제외. '현재 제조사가 59종으로 리뉴얼했다'고 확정하지 않는다.

## 구조·안전성
- 기존 제품 ID 유지, 단 9·19번은 추천 후보에서 제외한다.
- 기본 루틴 420개 합성 입력 자동 테스트 및 ID9·15·19 전용 테스트, ESLint, 프로덕션 빌드로 확인한다.
- 이번 검수의 보수적 제외 조치는 사용자 기록 삭제/추천 엔진 개편을 뜻하지 않는다.
