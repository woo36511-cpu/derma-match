# 브랜드 공식몰과 올리브영 상품 확인

**Brand catalog discovery watch**는 매일 24시간, 매시간 정각(한국 시간)에 브랜드 공식몰의
공개 상품 목록을 다시 확인한다. robots 정책에서 확인을 허용하지 않는 경로는 읽지 않는다.
이전 성공 스냅샷을 이어받으며, 일부 공식몰이 실패해도 해당 브랜드의 이전 목록은 보존한다.
상품 목록은 건마다 브랜드 공식 주소와 확인 출처를 남긴다.

올리브영은 별도다. 설정이 없으면 공개 검색으로 확인한 소량의 샘플만 교차 확인한다.
올리브영 또는 공급처가 사용을 허용한 JSON 피드가 있다면 GitHub Actions 비밀
`OLIVEYOUNG_APPROVED_FEED_URL`에 HTTPS 주소를 등록한다. 형식은
`data/oliveyoung-discovery-seed.json`과 동일하다. 설정 후 예약 실행이 피드 원본을 받아
브랜드 검수와 연결한다. 응답 실패 시 샘플을 전체 목록으로 가장하지 않는다.

두 보고서 모두 GitHub Actions의 `official-brand-discovery` 아티팩트에 저장한다.
기획·증정 구성은 단품의 성분이나 구매 링크를 상속하지 않는다. 수집 결과는 검토 대상이며
운영 추천·판매 상태 또는 전성분을 자동 확정하지 않는다.
