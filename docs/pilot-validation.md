# DearSince pilot: check that recommendations lead to an action

Recruit 3–5 volunteers who can try the survey with products they already use.
Do not ask them to buy a product or change a treatment just for this test.

Test these scenarios on mobile, then ask the user to explain the result in their own words:

| Scenario | Pass condition |
| --- | --- |
| Pustules + depressed or raised scars + cosmetic irritation | The first screen explains the immediate action. A separate candidate appears only for a verified non-overlapping applicable breakout; the irritated stage has its own action. |
| Closed bumps + red breakout | The result distinguishes the areas and does not suggest layering new treatments. |
| Existing routine is comfortable | The keep list is visible, and an unnecessary product is not presented as required. |
| Already using an acne product | The result explains whether to keep, reassess, or consider replacement using the answer and response. |
| Returning with prior use | Start or reopen the correct product/concern record; improvement and irritation are recorded separately. |

On the first visit, ask: “What would you do today?”, “Which product would you keep or change?”, and “What would make you stop or recheck?” On a return visit, ask what they actually did and whether they found the change record. Record comprehension and usability problems separately from recommendation concerns. Use generic participant labels and omit names or photos from issue reports.

## Before enabling any shared feedback ranking

Use only authenticated records with current protocol consent. Use the latest
record version so revoked consent cannot appear in a new analysis. Do not send
identifiers or small groups to the UI. The offline readiness helper counts only
groups with at least 30 distinct accounts and comparable completed records.
This is a pilot threshold, not proof of effectiveness. Before changing rankings,
review irritation and discontinuation separately, verify bias and data freshness,
and compare proposed changes with the current ranking. Do not use shared
feedback to change medication or safety rules.
